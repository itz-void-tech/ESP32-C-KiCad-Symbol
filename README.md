## 💡 The Problem

While working on ESP32-based electronics projects, I wanted to use an ESP32-C symbol in my KiCad schematics. However, I couldn't find a suitable, ready-to-use symbol that met my requirements.

Instead of letting that slow down the design process, I decided to create my own.

## 🚀 The Solution

This repository contains a custom KiCad schematic symbol for the ESP32-C, created to simplify its integration into electronic circuit designs.

The goal is simple: make it easier for developers, students, makers, and electronics enthusiasts to design circuits around the ESP32-C.

## 🛠️ Getting Started

### Requirements

- [KiCad](https://www.kicad.org/) — Electronic design automation software.
- The `esp32-c.kicad_sym` file from this repository.

### Installation

1. Clone or download this repository.
2. Open KiCad and launch the **Symbol Editor**.
3. Open the downloaded `esp32-c.kicad_sym` library.
4. Locate the ESP32-C symbol.
5. Copy the symbol into your project library or use KiCad's library management options to add the library for reuse.

**Tip:** For regular use across multiple projects, configure the symbol library in KiCad's **Preferences → Manage Symbol Libraries**.
